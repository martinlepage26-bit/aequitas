# Historical public-fixture protocol

**Retired for live model evaluation.** This protocol describes the public CI fixture set. Its expected dispositions and test assumptions are discoverable from the repository, so it cannot serve as an independent pre-model reference or authorize a live run.

CI continues to exercise the public cases with a stub model. For live synthetic evaluation, create a fresh seven-case unpublished set outside the repository and follow [the private baseline review instructions](case-agent-baseline-review-worksheet.md). The generated reviewer packet must be the only case input shown to reviewers before they freeze their independent findings. Each required reviewer must attest to independence from Aequitas development, no prior exposure to the public benchmark answers, and conflict disclosure before the baseline validates.

Any change to the private fixtures, evaluation policy, provider/model, prompt, or protocol changes the identity and invalidates prior review. The evaluator will require a fresh review and explicit one-run spend flag. A review of synthetic fixtures does not approve real-case processing or establish legal suitability.
